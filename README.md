# Assist Mod (Fabric 1.21.1)

Модули: TriggerBot (G) и AimAssist (H). Клавиши меняются в настройках управления.

Сборка: Java 21, затем `gradle wrapper` (один раз) и `./gradlew build`.
Готовый jar: build/libs/assistmod-1.0.0.jar. Нужен Fabric Loader и Fabric API.
Настройки модулей (дальность, FOV, плавность) — поля в классах модулей.
